# UI / 交互优化 Backlog

由 [UI 交互自检](ui_interaction_self_check.md) 或日常使用中发现的界面与交互问题，**摘一条记一行**，避免只在聊天或口头传递。

## 使用约定

- **状态**：`open` / `doing` / `done` / `wontfix`
- **优先级**：`P0`（阻塞） / `P1` / `P2` / `P3`
- 修复合并后把 **关联 PR** 写上，状态改为 `done`。
