## 0. 核心前提（所有框架的共同基础）

**价格和成交量是市场上唯一客观的信息，其他一切都是解读。**

所有主流趋势框架的发明者在不同时期独立得出了同一个结论：

> 成交量是价格行为的先行指标，而非滞后指标。

- 上涨周放量 + 下跌周缩量 → 健康的 Stage 2 上升趋势  
- 上涨周缩量 + 下跌周放量 → 趋势即将结束的警报

这一条比任何单个技术指标都重要。

## 1. 五大框架概览

### 1.1 Stan Weinstein — Stage Analysis（阶段分析）

**核心问题：这只股票处于哪个阶段？**

| 阶段 | 名称 | 特征 | 操作 |
|------|------|------|------|
| Stage 1 | 底部积累 | MA150走平，价格横盘，成交量低 | 观察等待 |
| Stage 2 | 上升趋势 | MA150向上，月线高点不断抬升，RS线强 | 唯一买入区 |
| Stage 3 | 顶部派发 | MA150走平或转向，价格震荡扩大 | 减仓出场 |
| Stage 4 | 下降趋势 | MA150向下，股价跌破MA150 | 空仓/做空 |

**关键指标：**
- MA150（30周均线）的斜率和方向——这是阶段判断的核心
- 月线高点是否持续抬升
- RS线（相对强度，vs 市场基准）同步或领先走强

**局限性：**
- MA150 是滞后指标，Stage 2 确认时通常股价已从真实底部上涨 20-40%
- 无法区分"Stage 2 早期"和"Stage 2 晚期延伸过度"——需要叠加其他工具
- 个股阶段分析必须在大盘健康的前提下才有效

### 1.2 William O'Neil — CAN SLIM & 底部形态

**核心问题：这只股票的基本面和机构资金参与度是否支持买入？**

**CAN SLIM 要素（基本面过滤器）：**
- **C** — Current Earnings：最近季度EPS同比增速 >25%
- **A** — Annual Earnings：过去3年年化EPS增速稳定
- **N** — New Product/Service/High：有驱动增长的新故事
- **S** — Supply & Demand：流通股不过多，机构在买入
- **L** — Leader：行业相对强度排名前列（RS Rating）
- **I** — Institutional Sponsorship：基金增持而非减持
- **M** — Market Direction：大盘处于上涨趋势（最重要的M）

**经典底部形态（技术面）：**

```
杯形底（Cup with Handle）：
  - 形成时间：7-65周
  - 回调深度：10-35%（牛市偏浅）
  - 把手（Handle）：1-2周，成交量萎缩
  - 买点：把手上轨突破，放量
  
平底底（Flat Base）：
  - 形成时间：至少5周
  - 回调深度：<15%（极强力特征）
  - 代表强势主力护盘
  - 买点：盘整上轨突破，放量

双底（Double Bottom）：
  - 第二底不能低于第一底
  - 中间反弹需有量能支撑
  - 买点：中间高点突破，放量
```

**关键洞见：**
机构资金（基金、ETF、大型投资机构）才是推动股价从底部到高点的真正力量，散户资金无法完成这个任务。底部形态的实质是机构在悄悄吸筹。

### 1.3 Mark Minervini — SEPA & VCP

**核心问题：在哪个精确位置执行买入？**

**趋势模板（Trend Template）——8个必须同时满足的条件：**

```
1. 股价 > MA150 且 > MA200
2. MA150 > MA200
3. MA200 至少上升 1 个月
4. MA50 > MA150 > MA200（均线多头排列）
5. 股价 > MA50
6. 股价距52周高点 < -25%（不在过度延伸区）
7. 股价 > 52周低点的 30%+（不在底部区域）
8. RS Rating > 70（相对强度排名前30%）
```

**VCP（波幅收窄形态 Volatility Contraction Pattern）：**

```
原理：每次回调的幅度比上一次更小，成交量在回调中不断萎缩
      → 浮筹被清洗，弹簧被压缩到最紧
      → 放量突破时，抛压最小，上涨阻力最小

示意：
  价格         ↗ 涨20% ↘ 回调10% ↗ 涨15% ↘ 回调5% ↗ 突破！
  成交量    ████  ███      ████  ██       ████  █      ██████
              收缩幅度逐步减小 ──────────────────────→
```

**Pivot Point（枢轴买点）：**
- 盘整结构的上轨即为 Pivot Point
- 买入在突破 Pivot Point 当日或次日
- 止损在盘整期最低价 -1 ATR 以下

### 1.4 Wyckoff — 供需分析与积累/派发

**核心问题：价格横盘阶段背后，是积累还是派发？**

Wyckoff 与 Weinstein 是同一件事的两种描述，但 Wyckoff 提供更多底层逻辑：

**积累阶段（对应 Stage 1 末期→Stage 2 初期）：**

```
PS（Preliminary Support）→ SC（抛售浪）→ AR（反弹）→ ST（二次测试）
→ Spring（弹簧，假跌破浮筹）→ SOS（强势上涨确认）→ LPS（末次回踩支撑）
→ 突破进入 Stage 2
```

**关键概念——Spring（弹簧测试）：**
积累末期常见的一次假跌破，价格短暂跌破支撑区后快速反弹，成交量不大。这是最后一次洗出弱手的机会，也是最接近底部的买点。Spring 之后的放量上涨是进入 Stage 2 的强烈信号。

**派发阶段（对应 Stage 3）：**
```
PSY（初始供应）→ BC（买入高潮）→ AR（下跌反应）→ ST（二次测试）
→ UTAD（最后一次上冲，陷阱）→ SOW（弱势确认）→ LPSY（末次测试）
→ 跌入 Stage 4
```

### 1.5 Nicolas Darvas — 箱体理论

**核心问题：最简单的趋势中继判断方式**

**规则：**
1. 股价在一个特定价格区间内反复震荡 → 定义为一个"箱体"
2. 箱体上轨突破 + 成交量放大 → 买入
3. 跌破箱体下轨 → 止损出场
4. 突破后形成新的更高箱体 → 重复
5. 每个新箱体都在前一个箱体之上 → 趋势持续的证明

**价值：**
这个框架把"Stage 2 趋势延续"的本质简化成了一句话：**趋势的本质是"涨一段、停一停、再涨"，箱体是"停一停"的可量化定义。**

## 2. 五层复合系统

这五个框架不是替代关系，而是过滤层级关系：

```
Layer 1：市场环境过滤（Weinstein 大盘阶段 + O'Neil M因子）
   ↓ 大盘 > MA200 且广度健康，才进入 Layer 2
   
Layer 2：个股阶段判断（Weinstein Stage 2 + Wyckoff 积累确认）
   ↓ Stage 2 且 RS线强势，才进入 Layer 3
   
Layer 3：底部形态确认（O'Neil 底部形态 + Minervini VCP + Darvas Box）
   ↓ 有可识别的盘整收窄结构，才进入 Layer 4
   
Layer 4：触发信号执行（Minervini Pivot Point + O'Neil 放量突破）
   ↓ 放量突破且次日不回落，才执行买入
   
Layer 5：风控执行（仓位分层 + 止损设置）
   → 见 buy_point_methodology_v1.md 第 5 节
```

**为什么是这个顺序：**
- Layer 1-2 过滤的是"方向性错误"——买了逆势的股票，再好的买点也是亏损
- Layer 3 过滤的是"时机性错误"——方向对但太早，还没蓄力完毕
- Layer 4 过滤的是"确认性错误"——结构对但突破是假的
- Layer 5 控制的是"执行性错误"——对的方向但仓位过重导致心态崩溃

## 3. 关键指标体系

### 3.1 不可或缺（每次必看）

| 指标 | 用途 | 层级 |
|------|------|------|
| MA50 / MA150 / MA200 排列和斜率 | 阶段判断基础 | Layer 2 |
| RS 线 vs 市场基准（非 RSI）| 相对强度，领先信号 | Layer 2 |
| 成交量分布（涨周 vs 跌周）| 积累 vs 派发判断 | Layer 3-4 |
| ATR（平均真实波动幅度）| VCP 波幅收窄量化 | Layer 3 |
| 突破日成交量 vs 均量比 | 突破真伪判断 | Layer 4 |

### 3.2 有参考价值（不能单独决策）

| 指标 | 有用的情景 | 误用场景 |
|------|-----------|---------|
| RSI | 极端值（>80 / <30）有意义 | 中间区间无意义，强趋势中会钝化 |
| MACD | 确认趋势方向 | 判断买卖点时机不准 |
| 布林带宽 | VCP 的代理指标 | 单独使用无效 |
| forwardPE | 估值锚定 | 周期股顶部 PE 最低，底部 PE 最高 |

### 3.3 经常被高估（谨慎依赖）

- **绝对 PE 值**：对成长股几乎无效（NVDA 2023 年 PE 已"贵"，但后来涨了 10 倍）
- **短周期震荡指标（KDJ、随机指标）**：强趋势中持续钝化
- **消息面和研报**：价格行为包含所有已知信息，消息永远是价格的滞后描述
- **分析师目标价**：在周期股中系统性偏差严重（顶部过乐观，底部过悲观）

## 4. RS 线 vs RSI：重要区分

这是最常见的混淆：

| | RS 线（Relative Strength Line）| RSI（Relative Strength Index）|
|---|---|---|
| 本质 | 股价 ÷ 基准指数的价格比率 | 一段时间内涨跌幅度的统计量 |
| 含义 | 这只股票跑赢/跑输大盘多少 | 这只股票的动能强弱 |
| 使用方式 | RS线在股价突破前先创新高 = 领先买入信号 | 超买/超卖参考，强趋势中无效 |
| 重要性 | 极高（CAN SLIM 的 L 因子本质就是这个）| 中等 |

**实践：** 看周线图时，RS 线必须和价格图并排看。一只理想的 Stage 2 股票，它的 RS 线应该早在价格突破前就已经创出新高。

## 5. 市场环境判断（经常被忽视的 Layer 1）

Stan Weinstein 的原话：**"80% 的股票随大盘涨跌"**。这意味着，如果大盘处于 Stage 3-4，个股 Stage 2 分析几乎无效。

**市场健康度判断清单：**

```
□ S&P 500 > MA200（最基础条件）
□ S&P 500 > MA50（更强的健康信号）
□ 新高股票数量 > 新低股票数量（市场广度正常）
□ 上涨个股数量 > 下跌个股数量（广度持续）
□ 过去 25 个交易日内 Distribution Days < 5（无密集出货信号）
```

如果上述任意 2 条以上不满足，应大幅降低新建仓频率。

## 6. 框架的局限性（质疑一切）

### 6.1 Weinstein Stage 的局限

- **滞后性**：MA150 确认 Stage 2 时，通常已错过底部 20-40% 的涨幅
- **阶段主观性**：边界情况难以客观判断（Stage 2 中期 vs 晚期）
- **延伸度无法量化**：同样是 Stage 2，+10% vs MA150 和 +120% vs MA150 风险完全不同
- **不适用于所有市场环境**：在市场流动性危机时（2008、2020 Q1），Stage 分析无效，所有股票同步崩溃

### 6.2 基本面分析的局限

- **财报数据滞后**：反映的是过去，而股价定价的是未来
- **分析师 EPS 预估系统性偏差**：周期顶部过乐观，周期底部过悲观
- **forwardPE 的陷阱**：低 forwardPE 在周期股顶部意味着"市场已 price-in 峰值 EPS"，是风险而非机会（MU 案例）
- **定性护城河不反映在财报中**：NVDA 的 CUDA 生态系统在资产负债表上不可见

### 6.3 技术形态识别的局限

- **形态都是后验的**：只有回头看才能清晰确认是哪种形态
- **主观性强**：两个有经验的交易者可能对同一图表有不同判断
- **假突破概率 30-50%**：即使满足所有条件，假突破依然常见

### 6.4 回测的陷阱

- **幸存者偏差**：只用现在还存活的好公司做历史回测，会高估策略效果
- **前视偏差**：财报数据会被修订，回测需要用"当时已知的"数据
- **过拟合**：参数调优过度，在历史数据好看但未来失效
