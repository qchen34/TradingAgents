# 个股买点分析方法论 v1

> 文档目的：把"好公司"转化为"好价格的可执行买点"。  
> 适用范围：AI 算力产业链核心标的（NVDA / AVGO / MU / VRT / GEV / ETN / ANET / MRVL / TER / COHR / ONTO / AMKR / ALAB / AMD / RKLB；可持续扩充）  
> 版本：v1 · 2026-05

---

## 0. 为什么需要这份方法论

直接让 LLM 输出 `等回踩 MA50-MA150×1.15` 这类模板化买点，在以下场景**完全无效**：

1. **延伸度极高的标的**：如 MU 距 MA150 +121%，回踩 MA150 意味着 $354（当前 $784），这种回踩只在**叙事崩溃**时发生。
2. **周期股顶部博弈**：`trailingPE 37x` 看起来贵，`forwardPE 7.7x` 看起来便宜——单看技术面 MA 不够，必须叠加估值锚定。
3. **市场情绪 vs 公允价值脱节**：股价已 price-in 极乐观的 forward EPS，但实际 EPS 兑现路径有 2-3 倍分歧。

→ 方法论必须把 **公允价值 / 隐含预期 / 技术结构 / 情绪与仓位** 四层结合起来。

## 1. 标的分层（先判断标的所处的"博弈结构"）

每个 ticker 在做买点判断前，先打标签：

| 分层 | 特征 | 适用策略 |
|---|---|---|
| **A. 趋势启动期** | Stage 2 早期，距 MA150 ±5% 内，刚突破长期盘整 | 主动建仓 + 突破回踩买点 |
| **B. 趋势延续期** | Stage 2 中期，距 MA150 +10%~+25%，月度高点持续抬升 | MA50 回踩 / 盘整突破 buy point B |
| **C. 顶部博弈期** | Stage 2 中后期，距 MA150 >+50%，距 52w 高 < -10%，PE 显著高于行业 | **不追高**，等回调 -15%~-25% 或换标的 |
| **D. 派发/转折期** | Stage 3，MA150 走平或下拐，量价背离 | 持币观望，等下一轮 |
| **E. 修复期** | Stage 1 后期，MA150 上拐，从底部走出 | 突破买点 A 候选 |

**核心 13 当前分类（占位，需每次刷新更新）**：见 `docs/case_studies/`。

## 2. 公允价值锚定（先回答"贵还是便宜"）

### 2.1 估值的四维度

```
Z1. 绝对 PE：trailingPE / forwardPE（基础锚）
Z2. 相对行业：PE / 行业代理 PE（SOXX/XLI/XLK trailingPE 作为基准）
Z3. PEG / EV/EBITDA：考虑增长后的估值合理性
Z4. 历史区间：当前 PE 处于过去 5y 区间的百分位
```

### 2.2 周期股的特殊处理

半导体（NVDA/AVGO/MU/MRVL/COHR/TER/ONTO/AMKR/ALAB）是典型周期股，PE 在周期不同位置含义完全不同：

| 周期位置 | 合理 NTM PE | 含义 |
|---|---|---|
| 周期底部 | 18-25x | EPS 处于低位，市场 price-in 复苏 |
| 周期上行 | 15-20x | EPS 快速兑现，PE 自然压缩 |
| 周期顶部 | 8-12x | EPS 创历史高，市场已开始担忧拐点 |
| 转折下行 | 25-40x+ | EPS 暴跌而股价滞后回落 |

**关键判断**：当前 forwardPE 极低（如 MU 7.7x），不代表"便宜"，代表**市场已假设峰值 EPS 持续可兑现**，这是**最高风险点**。

### 2.3 "隐含预期"反推

公允价值 = NTM EPS × 合理 NTM PE  
反过来：**当前价格隐含的 EPS** = 当前价 / 合理 NTM PE

操作：
1. 给一个合理 NTM PE 区间（如半导体周期上行期 15-20x）
2. 反推当前股价隐含的 EPS 区间
3. 对比分析师 EPS 区间（low / mean / high）
4. 判断：当前股价是 price-in 了 high case，还是 mean case？

## 3. 技术买点结构（四层）

### 3.1 经典 Weinstein / O'Neil 买点

- **买点 A（突破型）**：突破长期盘整箱体上沿 + 放量，MA150 已转上行
- **买点 A 回踩**：突破后回踩 MA50 ±3% 内不破位
- **买点 B（趋势中继）**：在 Stage 2 中期，强势盘整 3-5 周后再次突破
- **买点 B 低偏离区**：距 MA150 偏离 +5%~+15%（健康区间）

### 3.2 现实场景下的修正（针对 C 类延伸标的）

对于 C 类（顶部博弈期），传统的 MA 回踩没有触发条件。改用**事件 / 估值复合买点**：

| 买点类型 | 触发条件 | 止损参考 |
|---|---|---|
| **C1. 财报后回调** | 财报兑现 + 价格回踩 -15%~-25%，未跌破 MA50 | -8%（MA50 - 5%） |
| **C2. 强势盘整突破** | 顶部横盘 4-6 周，盘整箱体上轨突破 + 量能放大 | 盘整箱体下沿 |
| **C3. 估值修复点** | 价格回落使 forwardPE 回归至历史中位以下 | 同 C1 |
| **C4. 不买（仅观察）** | 距 MA150 > +30%、RSI > 80、距 52w 高 < -5% | N/A |

### 3.3 真崩盘买点（D 类）

只有当 **基本面叙事真崩塌**（HBM 价格雪崩 / 客户削减 capex / Geo-political 冲击），等待：
- 跌破 MA50 → 转为观察
- 回踩 MA150 ±5% + 月度高点开始抬升 → 买点 A 候选
- 距 52w 高 -35%~-50% 区间 + 季度营收同比仍正 → 价值回归型机会

## 4. 买点描述应包含的必备字段

LLM 输出或人工撰写买点时，**禁止只给一个价格**，必须给：

```yaml
分层判断: A/B/C/D/E
当前估值定位:
  forwardPE: 7.7x
  行业PE基准: 28x
  PE/行业PE: 0.27x  # 显著低于行业
  历史 PE 区间百分位: 90%  # 在 5y 区间内的位置
公允价值区间:
  保守 (low EPS × 低 PE):    $XXX  # 最差情况
  中性 (mean EPS × 中位 PE): $XXX  # 公允锚定
  乐观 (high EPS × 高 PE):   $XXX  # 最好情况
当前价隐含预期:
  按 NTM PE 15x 反推所需 EPS: $XX
  对比分析师 mean: 比 mean 高/低 XX%
  → 结论: price-in 了 高/中/低 情景

买点分层:
  A 仓 (轻仓试探, 30%):
    价位: $XXX
    触发: 财报回调或盘整突破
    止损: $XXX (-X%)
  B 仓 (主力建仓, 50%):
    价位: $XXX
    触发: ...
    止损: $XXX (-X%)
  C 仓 (加仓 / 突破跟随, 20%):
    价位: $XXX
    触发: ...
    止损: $XXX (-X%)

何种未来表现会让当前价偏高:
  - FY EPS < $XX  →  PE > 20x  →  贵
  - HBM 单价同比转负  →  周期拐点信号
  - 任意主要客户削减 AI capex guidance
  - RS vs QQQ 滑落 + 跌破 MA50
何种未来表现会让当前价合理:
  - FY EPS ≥ $XX 且 forward guidance 上调
  - HBM4 良率突破 / 客户 LOA 续签
  - 行业 capex 至少维持 YoY +XX%
```

---

## 5. 仓位与执行规则

1. **永不一次性满仓**：A/B/C 三档分层，单次不超过单只目标仓位的 50%
2. **止损刚性**：买入后跌破止损价（通常 -8%~-10%）必须减仓 50% 以上
3. **顶部博弈仓位上限**：C 类标的总仓位不超过组合 15%
4. **财报前减仓规则**：高估值标的财报前减仓至少 30%，等结果再决定方向

## 9. 附录：`technical.trend_buy` 与方法论条目的对应关系

个股追踪后端在 `technical` 中写入规则化对象 `trend_buy`（非 LLM），供总表、详情与 LLM prompt 对齐使用。

| `verdict` 枚举 | 含义（与上文分层的大致关系） | 主要触发思路 |
|----------------|------------------------------|--------------|
| `at_buy` | 趋势买点结构较成熟（偏 B 类健康区 + 多头排列） | 偏离 MA150 约 +3%～+22%、MA150 斜率为正、RSI 42～72、MACD 柱为正或斜率向上 |
| `near_buy` | 接近买点（偏 A 末 / B 初或刚金叉） | 贴近 MA150、近 25 日内 MA50 上穿 MA200，或 RSI 弱势区但 MACD 柱斜率向上 |
| `not_yet` | 未到买点 | 不满足上两类且未触发禁追 |
| `avoid_chase` | 禁追 / 延伸博弈（偏 C 类） | 延伸区/过度延伸、或 RSI≥78、或高偏离且贴近 52w 高 |

`conditions_if_not_buy` 为字符串列表，对应方法论中「若价格未到理想买点，下一笔应等待什么条件」的可执行描述；LLM 的 `next_buy_guidance` 应优先与之呼应，除非数据证明规则失效（并在叙述中说明）。
