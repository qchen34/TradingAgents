# Klarman — 个股深度分析 Playbook

## 2. Seth Klarman
**机构：** Baupost Group · **风格：** 硬核深度价值 / 逆向

### 核心信条
> "风险不是波动率，是永久性本金损失的概率。"

### 选股标准
- **安全边际**：至少 30–50% 折扣于保守估算的内在价值
- **资产价值**：偏好有形资产背书（房地产、自然资源、清算价值）
- **被忽视的市场**：机构不覆盖、指数不纳入、媒体冷门
- **下行保护**：即使分析完全错误，损失也有限

### 入场逻辑
- 极度低估 + 有明确的价值实现催化剂（并购、资产出售、管理层换届）
- 不追热点，耐心等待市场恐慌或错误定价

### 持仓 / 退出
- **仓位管理**：单一仓位通常不超过 5%，大量持有现金等待机会
- **退出触发**：价格回归内在价值、出现更好的机会、安全边际消失

### 对每只股票要问的问题
1. 如果我的分析完全错了，最坏情况是损失多少？
2. 价格折扣是真实的还是陷阱（价值陷阱）？
3. 有没有让价值得以实现的具体催化剂？
4. 现在为什么别人不愿意买它？

## 深度分析 Playbook（执行清单）

### 1. 适用边界
对照上文框架判断本标的是否适用；不适用须在 concern 中说明。

### 2. 分析步骤（必须逐步覆盖，摘要写入 analysis_steps_done 数组）
1. 核对 computed_context 中的价格、均线、估值事实
2. 按本框架标准评估并给出 score（1-5）
3. 确定 verdict：buy / watch / avoid
4. 给出理想买入、最高追价、触发条件（纯数字）
5. 给出止损价与逻辑（stop.price < ideal_price <= max_chase_price）
6. 给出持有周期与仓位建议

### 3. 买点与止损
价位须引用 computed_context，禁止 N/A 或纯文字价。

### 4. 深度 JSON 额外字段
investment_thesis, bull_case, bear_case, catalysts（2-4条）, position_sizing, analysis_steps_done（3-6条短句）
