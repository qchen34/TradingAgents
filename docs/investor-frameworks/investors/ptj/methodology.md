# PTJ — 个股深度分析 Playbook

## 5. Paul Tudor Jones
**机构：** Tudor Investment Corp · **风格：** 趋势 + 宏观 + 严格风控

### 核心信条
> "最重要的规则是强有力的防守。如果你每天早上起来，第一件事是想今天要亏多少，而不是赚多少，那你就走在正确的路上了。"

### 核心框架
- **5:1 赔率原则**：每笔交易预期回报必须是潜在损失的 5 倍
- **止损优先**：进场前先确定止损位，仓位大小由止损计算
- **趋势确认**：不在趋势不明的市场中做大赌注

### 分析方法
- 技术面（移动均线、相对强弱）+ 宏观背景 + 市场情绪
- 价格是最诚实的信号——跌破支撑就出，不争论
- 关注大型机构资金流动（商业头寸报告 COT）

### 对每只股票要问的问题
1. 这笔交易的赔率是否至少 3:1，理想 5:1？
2. 止损在哪里？仓位是否根据止损计算的？
3. 趋势是否明确，还是在震荡区间中？

## 深度分析 Playbook（执行清单）

### 1. 适用边界
对照上文框架判断本标的是否适用；不适用须在 concern 中说明。

### 2. 分析步骤（必须逐步覆盖，摘要写入 analysis_steps_done 数组）
1. 核对 computed_context 中的价格、均线、估值事实
2. 按本框架标准评估并给出 score（1-5）
3. 确定 verdict：buy / watch / avoid
4. 给出理想买入、最高追价、触发条件（纯数字）
5. 给出止损价与逻辑（stop.price < ideal_price <= max_chase_price）
6. 给出持有周期与仓位建议

### 3. 买点与止损
价位须引用 computed_context，禁止 N/A 或纯文字价。

### 4. 深度 JSON 额外字段
investment_thesis, bull_case, bear_case, catalysts（2-4条）, position_sizing, analysis_steps_done（3-6条短句）
