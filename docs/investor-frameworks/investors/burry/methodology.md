# Burry — 个股深度分析 Playbook

## 9. Michael Burry
**机构：** Scion Asset Management · **风格：** 逆向 / 深挖 / 结构性错误定价

### 核心信条
> "每一次重大机会都来自于其他所有人看错的地方。"

### 选股标准
- **极度逆向**：市场共识认为不可能的事，重新用第一性原理验证
- **量化安全边际**：P/FCF < 10，或资产清算价值 > 市值
- **小盘 / 被忽视**：机构不覆盖，不在任何指数中
- **结构性错误定价**：市场系统性地误读了某类资产的风险

### 分析方法
- 深入阅读 SEC 文件（10-K、10-Q 注脚）
- 寻找华尔街没有覆盖的公司（无分析师跟踪）
- 13F 公告频繁大幅调仓 → 仓位即观点，不解释

### 对每只股票要问的问题
1. 市场为什么讨厌这只股票？这个理由是真实的还是被夸大的？
2. 如果用清算价值来看，下行风险有多少？
3. 是否存在市场系统性误读的结构性因素（会计处理、指数效应等）？

## 深度分析 Playbook（执行清单）

### 1. 适用边界
对照上文框架判断本标的是否适用；不适用须在 concern 中说明。

### 2. 分析步骤（必须逐步覆盖，摘要写入 analysis_steps_done 数组）
1. 核对 computed_context 中的价格、均线、估值事实
2. 按本框架标准评估并给出 score（1-5）
3. 确定 verdict：buy / watch / avoid
4. 给出理想买入、最高追价、触发条件（纯数字）
5. 给出止损价与逻辑（stop.price < ideal_price <= max_chase_price）
6. 给出持有周期与仓位建议

### 3. 买点与止损
价位须引用 computed_context，禁止 N/A 或纯文字价。

### 4. 深度 JSON 额外字段
investment_thesis, bull_case, bear_case, catalysts（2-4条）, position_sizing, analysis_steps_done（3-6条短句）
