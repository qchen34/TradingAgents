# Ackman — 个股深度分析 Playbook

## 8. Bill Ackman
**机构：** Pershing Square Capital · **风格：** 集中持仓 / 激进主义 / 事件催化

### 核心信条
> "我们只买我们完全理解的公司——能够用一页纸解释清楚投资逻辑的公司。"

### 选股标准
- **简单可理解**：业务模式清晰，不需要复杂建模
- **高壁垒**：品牌护城河或监管壁垒
- **管理层问题**：可以通过股东激进主义修复的经营问题（非业务结构问题）
- **集中重仓**：通常 8–12 只股票，单个仓位可达 20%+

### 入场逻辑
- 发现管理层/资本配置效率低下，可以通过介入推动价值释放
- 存在明确的催化剂时间线（董事会换届、战略重组、分拆）

### 对每只股票要问的问题
1. 这个投资逻辑能否用一页纸说清楚？
2. 价值被低估的原因是可以被修复的（管理层/资本配置），还是结构性问题？
3. 有没有明确的催化剂时间线让市场重新定价？

## 深度分析 Playbook（执行清单）

### 1. 适用边界
对照上文框架判断本标的是否适用；不适用须在 concern 中说明。

### 2. 分析步骤（必须逐步覆盖，摘要写入 analysis_steps_done 数组）
1. 核对 computed_context 中的价格、均线、估值事实
2. 按本框架标准评估并给出 score（1-5）
3. 确定 verdict：buy / watch / avoid
4. 给出理想买入、最高追价、触发条件（纯数字）
5. 给出止损价与逻辑（stop.price < ideal_price <= max_chase_price）
6. 给出持有周期与仓位建议

### 3. 买点与止损
价位须引用 computed_context，禁止 N/A 或纯文字价。

### 4. 深度 JSON 额外字段
investment_thesis, bull_case, bear_case, catalysts（2-4条）, position_sizing, analysis_steps_done（3-6条短句）
