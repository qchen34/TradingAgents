# Marks — 个股深度分析 Playbook

## 3. Howard Marks
**机构：** Oaktree Capital · **风格：** 周期投资 / 风险管理

### 核心信条
> "你不能预测，但你可以准备。知道我们处于周期的哪个位置，比知道下一步是什么更重要。"

### 核心框架
- **市场温度计**：当前市场处于乐观还是悲观端？贪婪还是恐惧？
- **第二层思维**：不问"这家公司好不好"，问"共识是否已过度反映这个判断"
- **风险感知 vs 实际风险**：当大家都认为没风险时，风险最大

### 分析方法
- 阅读市场情绪信号：信用利差、IPO 热度、杠杆水平、媒体情绪
- 判断当前周期位置 → 决定进攻性（多配权益）还是防守性（持有现金/债券）
- 在信用周期底部买高收益债，在股票被过度悲观时增配

### 对每只股票要问的问题
1. 市场对这只股票的共识是什么？共识是否已经过度定价？
2. 如果现在买，是在市场恐惧中逆向，还是在乐观中追高？
3. 这只股票当前价格反映的预期，是悲观的一端还是乐观的一端？

## 深度分析 Playbook（执行清单）

### 1. 适用边界
对照上文框架判断本标的是否适用；不适用须在 concern 中说明。

### 2. 分析步骤（必须逐步覆盖，摘要写入 analysis_steps_done 数组）
1. 核对 computed_context 中的价格、均线、估值事实
2. 按本框架标准评估并给出 score（1-5）
3. 确定 verdict：buy / watch / avoid
4. 给出理想买入、最高追价、触发条件（纯数字）
5. 给出止损价与逻辑（stop.price < ideal_price <= max_chase_price）
6. 给出持有周期与仓位建议

### 3. 买点与止损
价位须引用 computed_context，禁止 N/A 或纯文字价。

### 4. 深度 JSON 额外字段
investment_thesis, bull_case, bear_case, catalysts（2-4条）, position_sizing, analysis_steps_done（3-6条短句）
