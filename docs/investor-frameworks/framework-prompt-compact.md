# 大佬框架精简版（System Prompt 注入用）

每位：3 条判断标准 · 买入信号 · 止损逻辑 · 评分（5=强烈支持买入，1=明确回避）

---

## Buffett
- 标准：护城河可维持10年+；ROIC/FCF 质量；管理层股东导向；定价权
- 买入：优秀生意+合理价（PE 不超行业1.5x 或 FCF yield>4%）
- 止损：护城河受损/基本面恶化，非价格波动
- 评分：5=四项皆强；每缺一项扣1

## Klarman
- 标准：30–50% 安全边际；下行有限；被忽视；有催化剂
- 买入：深度折价+价值实现路径清晰
- 止损：安全边际消失或更好机会出现
- 评分：5=折价+催化剂+下行可控

## Marks
- 标准：市场温度；第二层思维（共识是否过度定价）；风险感知错位
- 买入：恐惧端逆向或共识尚未透支乐观
- 止损：周期位置反转至过度乐观
- 评分：5=逆向+共识未透支

## Druckenmiller
- 标准：宏观流动性；18个月利润前瞻；价格趋势+量能
- 买入：宏观顺风+突破关键均线+放量
- 止损：宏观转弱或个股逻辑破裂，快速砍仓
- 评分：5=三项齐；缺一项扣1

## PTJ
- 标准：赔率≥3:1（理想5:1）；止损先定；趋势明确
- 买入：趋势确认+赔率达标+仓位按止损定
- 止损：跌破预设技术位，不争论
- 评分：5=赔率+趋势+纪律齐备

## Dalio
- 标准：债务/信贷周期位置；资产在宏观情景下的表现；组合风险贡献
- 买入：宏观情景匹配资产历史优势区
- 止损：周期阶段切换不利
- 评分：5=周期+配置逻辑一致

## Cathie Wood
- 标准：颠覆平台+大TAM；渗透率早期；Wright成本曲线
- 买入：渗透率<5%+成本曲线仍陡降
- 止损：技术路径证伪或TAM假设失效
- 评分：5=颠覆+渗透率+成本曲线

## Ackman
- 标准：一页纸能说清；高壁垒；可修复的管理/资本问题；催化剂时间线
- 买入：低估+可修复+催化剂明确
- 止损：逻辑不可修复或催化剂落空
- 评分：5=简洁逻辑+催化剂

## Burry
- 标准：极度逆向；P/FCF或清算价值保护；结构性误定价
- 买入：市场厌恶理由被夸大+清算价值支撑
- 止损：误读被证伪或结构性问题真实
- 评分：5=逆向+安全边际+误定价

## Asness
- 标准：价值/动量/质量/低波四因子；综合不低；与价格一致
- 买入：多因子综合靠前且无单因子极差
- 止损：因子逻辑系统性失效（纪律减仓）
- 评分：5=四因子均衡偏强

## Greenblatt
- 标准：收益率(EBIT/EV)+ROIC 排名；特殊情况（分拆/重组）
- 买入：神奇公式靠前+暂时性利空
- 止损：结构性非暂时问题
- 评分：5=收益率+ROIC双高

## Loeb
- 标准：资本配置效率；分拆价值；激进可推动的改善
- 买入：价值毁灭可修复+分拆/回购催化剂
- 止损：管理层抵制且无外部压力
- 评分：5=折价+可推动催化剂

## Weinstein
- 标准：Stage（MA150方向+偏离）；量价健康；RS vs 大盘
- 买入：Stage 2+健康区/买点A/B+RS支持
- 止损：跌破MA150或进入Stage3/4；禁追延伸过度
- 评分：5=Stage2+量价+RS+规则买点一致；Stage3/4 上限2分

```json
    "max_chase_price": 1060.0,
    "trigger_condition": "回踩 MA50 缩量",
    "note": "现价高于理想区"
  },
  "stop_loss": {
    "price": 940.0,
    "pct_from_ideal": -7.8,
    "logic": "基本面护城河假设被破坏"
  },
  "holding_period": {

  }

```
