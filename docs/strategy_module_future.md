# 策略模块（后续规划，未实现）

本文件供后续实现「策略」页与回测功能时对照，**当前 Web 端策略菜单仅为占位**。

## 1. 目标

- 以**傻瓜式表单**记录个人策略（如 LRS、Sell Put 等），与个股分析、报告分离。
- 远期可接入 TradingAgents：通过**独立 System Prompt / 工具**读取策略库，再跑分析（需改框架输入，不在本阶段范围）。
- 远期可增加**回测**：策略定义 + 历史价格区间 → 收益、回撤、夏普等。

## 2. 建议字段（策略库）

| 字段 | 说明 |
|------|------|
| 策略名称 | 唯一标识或展示名 |
| 参考指标 | 当前主要参考的技术/宏观/波动率指标（多行文本） |
| 标的 | 逗号分隔 ticker，存大写列表 |
| 策略说明 | 多行：逻辑概述 |
| 买入规则 | 何时、何条件建仓 |
| 卖出规则 | 止盈/止损/时间退出 |
| 交易佣金 | 数值 + 计费方式说明 |
| 震荡市应对 | 横盘或高波动时的操作原则 |
| 备注 | 可选 |
| 创建/更新时间 | ISO 时间 |

持久化可沿用 `data/*.json` 模式（如 `data/strategies.json`）或后续迁移数据库。

## 3. 回测扩展（路线图）

- **输入**：策略 ID、起止日期、标的、初始资金、佣金参数。
- **行情**：Yahoo 日线或本地 CSV。
- **输出**：权益曲线、最大回撤、年化收益、夏普、交易笔数等。
- **与策略库关联**：回测配置引用已保存的策略记录，便于复现。

## 4. 与仪表盘的关系

- 仪表盘侧重**当日市场与新闻**；策略库侧重**个人规则与历史验证**，数据流独立。
